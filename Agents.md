# Orientações do repositório

- Preserve a arquitetura e os padrões já utilizados no DarkStudio.
- Antes de alterar a interface, inspecione os arquivos HTML, CSS e JavaScript envolvidos.
- Mantenha compatibilidade com desktop e dispositivos móveis.
- Prefira correções localizadas, evitando duplicação de regras CSS e alterações não relacionadas.
- Preserve funcionalidades existentes do Workspace, do editor Monaco e do NightCoder.
- O NightCoder só pode executar alterações no Workspace após aprovação explícita do usuário.
- Não exponha segredos, credenciais ou arquivos binários às ferramentas do agente.
- Escreva mensagens de commit em português (Brasil), identificadas como `GPT [6] - {modificação realizada}`.
