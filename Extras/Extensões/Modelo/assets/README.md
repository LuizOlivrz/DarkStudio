# Recursos da extensão

Guarde nesta pasta os arquivos usados pela extensão, separados por tipo:

- `images/`: fotos e imagens.
- `videos/`: vídeos.
- `icons/`: ícones SVG/PNG.
- `audio/`: sons e músicas.
- `fonts/`: fontes locais.

Crie apenas as subpastas necessárias. Referencie os recursos usando caminhos relativos à pasta da extensão.
