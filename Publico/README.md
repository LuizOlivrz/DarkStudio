# Publico — metadados de distribuição

Esta pasta é reservada a informações mínimas para o verificador de atualizações do DarkStudio.

## O que pode ficar aqui
- versão pública atual;
- notas resumidas de versão;
- endereço de um pacote de atualização publicado separadamente.

## O que não deve ficar aqui
- código-fonte da aplicação;
- chaves, tokens ou segredos;
- arquivos internos, lógica proprietária ou o pacote completo do projeto sem uma decisão explícita de publicação.

**Importante:** esta pasta está dentro do repositório oficial. Enquanto o repositório continuar privado, estes arquivos também não serão acessíveis anonimamente. Para o Electron consultá-los sem credenciais, será necessário publicar apenas esta pasta em um repositório público separado ou servir os metadados por um endpoint público seguro.
